## #10 缺口 1 修复：claude linux pattern

- 根因：`resolve_github` 恒按 `asset_pattern` 对 release 清单重筛（pin 只锁 tag 不锁资产名），catalog 的 `linux_asset_pattern` 写成 x86_64，而 v2.1.251 官方实际资产名是 claude-linux-x64.tar.gz（九资产清单实测）；lan-pve 报「未找到匹配资产」即此。pin 三键本身是对的（oma 实证值迁入），错的只是两行 pattern。
- 修复：catalog 两行 pattern 改 x64；官方 SHASUMS256.txt 与 pin 三平台 sha 逐字一致（4fda59 / 02e1e8 / 22e6a1）；镜像侧拉 tar 实证 linux 包单文件 claude 居根，targz 解 `~/.local/bin` 即 PATH 命中；mac 资产名 claude-darwin-arm64.tar.gz 本就与 pattern 吻合。
- 机检：catalog_lint 新规则「pin 资产名必被同平台 asset_pattern 命中」（拼写族零网络红灯，D28 清单化延续）；真仓与夹具 2/2 绿，顺带证明真仓无其他 pattern 暗雷。
- 验证：独立 TOML 解析核验三平台 pattern 各唯一命中资产、sums 行命中；catalog_lint 2/2 绿（本会话 shell 无 VS 环境，经 vcvars64.bat 导入后跑通，同 09-09 日记坑）。
